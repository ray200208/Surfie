# Surfie — Zero-Trust Chrome Extension Side Panel POC

Built by **Team PandaPilot** (SSN College of Engineering • Team ID: `e17b46ca`) for **wHACKiest 2026 — Track 2: Beyond the Browser**.

## Overview

**Surfie** is a privacy-first, zero-backend interactive Chrome Browser + Extension Side Panel Proof-of-Concept uniting four everyday browser workflows inside a layered, cheapest-first, zero-trust architecture:

1. **Discover (Paywall Alert & Guided Spotlight):** Proactively flags hidden free-tier export caps/watermarks with verified ₹0 alternatives, and offers a Shadow-DOM Guided Spotlight in English, Hindi, and Tamil.
2. **Compare (Interactive Visual Mind Map):** Powered by `@xyflow/react`, compares open product/broadband tabs with deterministic JS true-cost normalization (1st-year total & effective monthly cost incl. GST), explicit *"Not stated on this page"* fallbacks, clickable dark-pattern source links, and an indirect prompt-injection firewall.
3. **Fill Form (Form Co-Pilot & Tamil/Tanglish Voice):** Local Persona Vault (College vs. Personal) with 1-click safe auto-fill, click-to-switch local overrides, hard-locked Password/OTP human hand-off, Focus Mode, Zero-Leak Cloud Payload inspection (`0 Bytes PII Sent`), and Tamil/Tanglish Voice-to-Form.
4. **Replay (₹0 Cached Workflows & Pre-Submit Safety Gate):** Replays saved LMS steps locally in `<1s` at ₹0 AI tokens and pauses at a Mandatory Pre-Submit Safety Gate with a live **Dynamic Page Tampering** abort demo.

## Tech Stack

- **Frontend:** React 19, TypeScript, Vite 6, Tailwind CSS v4
- **Visual Canvas:** `@xyflow/react`
- **Icons:** `lucide-react`
- **Architecture:** 100% client-side (zero backend required for the interactive POC)
